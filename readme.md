# Учебный проект Task Manager

Простой REST API проект для управления задачами (работами, заданиями), написанный на FastAPI. Проект создан для изучения основ разработки на FastAPI Python, использования Git, CI/CD и контейнеризации.

---

## 📝 О проекте

Приложение реализует базовые CRUD-операции (создание, чтение, обновление, удаление) для задач.  
В текущей версии (результат выполнения Практических работ №2 и №3) реализовано:

- **FastAPI** и автоматическая документация Swagger UI;
- работа с JSON и Pydantic-схемами;
- **Тестирование** (pytest) с покрытием кода более 70%;
- **CI (Continuous Integration / Непрерывная интеграция)** - автоматическая сборка и проверка кода;
- Документация (docstring) методов.

> ⚠️ В практической работе №4 предстоит провести **рефакторинг** этого проекта, 
> так как сейчас весь код (модели, база данных и эндпоинты) находится в одном файле `main.py`.

## 📚 API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/tasks` | Получить список всех задач |
| POST | `/tasks` | Создать новую задачу |
| GET | `/tasks/{task_id}` | Получить задачу по ID |
| PUT | `/tasks/{task_id}` | Обновить задачу по ID |
| DELETE | `/tasks/{task_id}` | Удалить задачу по ID |
| GET | `/health` | Проверка работоспособности приложения |

### Модель задачи
- `id` (UUID)
- `title` (str, 1-100 символов)
- `description` (str, до 500 символов)
- `is_completed` (bool)
- `priority` (enum: `low`, `medium`, `high`)
- `created_at` (datetime)
- `updated_at` (datetime)
